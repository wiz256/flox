  Robustness Pipeline Summary

  What's new in crush_grid:

  1. Neighborhood Plateau Detection
  - Per-strategy axis definitions for all 13 strategies
  - NeighborMap class builds param-to-index lookup, finds ±1 step neighbors
  - Computes plateauRatio (fraction of profitable neighbors) and avgNeighborSharpe
  - 594 of 1594 combos have plateauRatio >= 0.3 (the rest are noise)

  2. Walk-Forward Validation (custom, uses full OHLCV)
  - Anchored mode: train window grows from bar 0, test window slides forward
  - 5 folds by default, configurable --wfo-folds
  - Pass criteria: test Sharpe > 0, degradation >= 0.3, min 5 test trades
  - Runs on top-K candidates after plateau filter

  3. Robust Ranking
  - robustScore = sharpe * plateauRatio — penalizes isolated spikes
  - Key finding: The original #1 by raw Sharpe (keltner_squeeze, 16.04) has plateau=0.60 and only 20% WFO pass rate — correctly demoted to #7
  - True robust winner: ema_crossover(f=21,s=34,adx=25) — 100% WFO pass rate, plateauRatio=1.0
  - ema_crossover is the most robust strategy family: 97.7% of combos profitable, avg plateau=0.98
