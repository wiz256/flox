## What's implemented in  main.cpp  v2

### 1. Position Sizing: $1000 USDT notional per trade

  Quantity qtyFromNotional(double price) → $1000 / price

Every  enterLong / enterShort  calls this with current close price. BTC at $100K → 0.01 BTC. DOGE at $0.10 → 10,000
DOGE. Same dollar risk across all 40 coins.

### 2. Min Trades Gate: 30 trades minimum

Any combo with <30 trades is excluded from the grid results entirely.

### 3. Multi-dimensional Plateau Detection

• For each best combo, finds all neighbors within 30% of param range on all dimensions (p1, p2, p3)
• Requires ≥3 neighbors
• Computes plateau ratio = fraction of neighbors with Sharpe ≥80% of best
• Computes relative variance = std(neighbor Sharpes) / |best Sharpe|
• Plateau = true if ratio ≥50% AND rel_variance < 0.15 (matching  lib/analysis/plateau.py )

### 4. Walk-Forward Validation (always runs, not conditional)

• 5 folds, each 70/30 train/test split
• Rolling (sliding) window — not anchored
• Pass = OOS/IS Sharpe ratio ≥ 0.6 AND OOS Sharpe > 0

### 5. White's Reality Check (stationary bootstrap)

• Uses strategy's per-bar equity returns (not underlying returns — that was a bug in v1)
• Stationary bootstrap with Politis-Romano block resampling (block size = √T)
• 5,000 bootstrap iterations
• p-value < 0.05 = statistically significant

### 6. Lookahead Guard

• Runs strategy on full data, then on 80% truncated data
• Compares trade counts — must be within 15% of expected

### 7. Promotion Gate (all 5 must pass)

 plateau.isPlateau && wf.passed && wrc_p < 0.05 && noLookahead && sharpe > 0

### Results: 245,160 combos in 2m28s

• 306/960 have plateaus
• 102/960 pass plateau + walk-forward
• 0/960 pass all 5 gates — WRC blocks everything (p-values ~0.50)

The WRC result is the key finding: at $1000 notional on 4H bars, none of these 8 strategies produce per-bar returns that
are statistically significant after the bootstrap correction. The Sharpe ratios look high (10-18) but the return series
has too much variance per-bar for the bootstrap to confirm it's not luck.
