### WFO Answer

Training in our case = the grid search itself. When you run the grid over the full period and pick the best Sharpe, that
IS the "training" (parameter selection). WFO then tests whether those selected parameters hold up on unseen time
windows. You can't skip it and "just test different periods" because without WFO's strict temporal separation, you can
accidentally overfit to the entire dataset's structure. The grid search sees ALL the data → WFO enforces that the
selected params generalize to data the grid never "trained" on.
