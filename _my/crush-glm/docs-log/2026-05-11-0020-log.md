• Grid search finds the best params on ALL data (2 years)
• WFO asks: "if I had only seen the first 18 months, would I have picked the same params?"
• If the answer is yes (same params are best on multiple sub-periods), the edge is robust
• If the answer is no (different params are best on different periods), you're overfitting to the full period's
structure
